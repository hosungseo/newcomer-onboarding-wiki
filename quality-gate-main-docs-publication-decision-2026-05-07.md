# quality-gate — main:/docs publication decision

## pass criteria

- `docs/index.html` link checks pass on the target publication branch.
- root markdown wikilinks resolve before publication.
- Pages source branch/path is intentionally selected.

## wait criteria

- feature branch has intended docs but `main:/docs` still serves older gateway content.

## fail criteria

- live Pages exposes missing root markdown links, sensitive material, or a branch/path not approved for publication.
