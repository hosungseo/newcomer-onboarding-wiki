# Checklist — router existing hub entry promotion safety (2026-05-07)

## Purpose

Use this checklist before promoting [[router-existing-hub-entry-index-2026-05-07]] into README, landing, docs index, or agent-readable catalogs. It is a safety artifact only: it prepares the promotion path without editing those surfaces in this lane.

## Promotion pre-check

- [ ] The promoted target is exactly [[router-existing-hub-entry-index-2026-05-07]].
- [ ] The router remains an entry index, not a replacement for existing hubs.
- [ ] The promotion copy says "try existing hub entries first" before any new hub naming.
- [ ] The promotion points to one next operational control: [[process-existing-hub-entry-decision-2026-05-07]] or [[checklist-router-existing-hub-before-new-hub-2026-05-07]].
- [ ] The low-density fallback remains [[section-low-density-hub-path-exposure-2026-05-07]], not a duplicate hub.

## Surface-specific checks

- [ ] README placement: add it under the newcomer execution-boundary route list, near the current low-density section entries.
- [ ] Landing placement: expose it as a router for ambiguous first nouns, not as a new learning path.
- [ ] Docs index placement: add one link label that preserves the router's date and purpose.
- [ ] Agent-readable placement: describe the minimal handoff fields from [[router-existing-hub-entry-index-2026-05-07]] rather than copying every route row.

## Wikilink contract

- [ ] Every wikilink in the promotion target already resolves on the root markdown surface.
- [ ] The promotion does not introduce a wikilink to a generated HTML page, data file, or external URL.
- [ ] If a target surface uses normal markdown links instead of wikilinks, the link text still maps back to an existing root markdown file.

## Stop / forbidden lines

- Stop if the promotion would edit, rename, or create a hub.
- Stop if any route in [[router-existing-hub-entry-index-2026-05-07]] has a missing root markdown target.
- Stop if the public copy implies coverage of private HR records, non-public budget strategy, internal deliberation, personal data, or legal-advice conclusions.
- Forbidden in this lane: editing README.md, docs/index.html, landing files, graph/data files, generated catalogs, or existing hubs.
- Forbidden in this lane: commit, push, deletion, renaming, or broad refactor.
