# Checklist — existing hub entry decision (2026-05-07)

## Purpose

Use this checklist before routing a newcomer question into an existing hub when the priority axes already have a hub or an accepted section-level route. Pair it with [[process-existing-hub-entry-decision-2026-05-07]] and [[section-low-density-hub-path-exposure-2026-05-07]].

## Pre-check

- [ ] I am choosing among existing roots, not proposing a new hub.
- [ ] The candidate root exists as a root markdown note.
- [ ] The request can be answered with public-only learning/routing material.
- [ ] The chosen entry point is either [[hub-기관또는기능]], [[hub-예산대응]], [[hub-인사]], or [[section-low-density-hub-path-exposure-2026-05-07]].

## Entry choice

- [ ] Institution, unfamiliar function, or portfolio-first wording → [[hub-기관또는기능]].
- [ ] Budget, request material, execution, contract/procurement money flow, or budget-facing disclosure boundary → [[hub-예산대응]].
- [ ] Appointment, transfer, leave, promotion, training, e사람, personnel record, or HR calculation → [[hub-인사]].
- [ ] 민원대응, 홍보대응, 법령대응, 협업회의운영, or low-density route exposure → [[section-low-density-hub-path-exposure-2026-05-07]].

## Handoff check

- [ ] The handoff says why this entry came first.
- [ ] The handoff names one next existing route, not a bundle of every possible route.
- [ ] If two axes compete, the first stable noun is fixed before adding the second route.
- [ ] If the route points to a low-density axis, it uses the section checkpoint rather than inventing a duplicate hub.

## Stop / forbidden lines

- Stop if any chosen wikilink is missing or points outside the root markdown surface.
- Stop if the request depends on private data, internal strategy, personal HR facts, non-public deliberation, or legal advice.
- Forbidden in this lane: editing existing hubs, README.md, docs/index.html, landing files, graph/data files, or generated catalogs.
- Forbidden in this lane: commit, push, deletion, renaming, or broad refactor.
