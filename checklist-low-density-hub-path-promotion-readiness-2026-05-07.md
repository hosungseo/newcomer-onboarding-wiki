# Checklist — low-density hub/path promotion readiness (2026-05-07)

## Scope

Readiness checklist for deciding whether [[section-low-density-hub-path-exposure-2026-05-07]] can be promoted into a landing/README/docs surface without overexposing the newcomer wiki.

## Readiness checks

- [ ] Promotion source is [[section-low-density-hub-path-exposure-2026-05-07]], not a one-off chat summary.
- [ ] Coverage source is [[coverage-low-density-hub-path-exposure-2026-05-07]].
- [ ] Docs/landing density source is [[coverage-docs-landing-low-density-newcomer-paths-2026-05]].
- [ ] Every promoted wikilink already resolves as a root markdown note.
- [ ] The promoted block has at most three first-click routes on the visible surface.
- [ ] Each first-click route has one next action: walkthrough, checklist, or quality gate.
- [ ] No coverage/manifest/quality cluster is exposed wholesale unless the surface is maintainer-facing.
- [ ] Public-only wording is used; no private deliberation, personal data, unresolved legal advice, or internal review line is included.
- [ ] Verification plan is written before promotion: root wikilink check plus docs/index link check when docs/index.html is touched.

## Recommended minimum bundle

- Process guardrail: [[process-low-density-hub-path-promotion-readiness-2026-05-07]]

## Stop / forbidden lines

- Stop if README.md, docs/index.html, landing files, graph/data, or generated catalogs must be edited but no explicit promotion authorization exists.
- Stop if a new route would duplicate [[section-execution-boundary-routes-2026-05]] without clarifying the audience or entrypoint.
- Forbidden: commit, push, deletion, mass rename, or changing existing root notes in this Lane B artifact pass.
- Forbidden: placeholder wikilinks, non-public facts, private names/details, or policy/legal conclusions not grounded in public notes.
