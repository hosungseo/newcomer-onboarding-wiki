# Checklist — use existing-hub router before creating a new hub (2026-05-07)

## Purpose

Use this checklist before proposing or drafting any new hub. The required first move is to check [[router-existing-hub-entry-index-2026-05-07]], then land in an existing hub or section wherever possible.

Pair this with [[checklist-existing-hub-entry-decision-2026-05-07]] and [[process-existing-hub-entry-decision-2026-05-07]].

## Pre-check

- [ ] I am considering a new hub only because an incoming question does not obviously fit an existing entry.
- [ ] I checked whether the question can start from [[hub-기관또는기능]], [[hub-예산대응]], [[hub-인사]], or [[section-low-density-hub-path-exposure-2026-05-07]].
- [ ] I identified the user's first stable noun before following secondary axes.
- [ ] I checked the existing-hub decision checklist before writing a hub filename.
- [ ] I can state the missing route in one sentence without duplicating an existing hub's scope.

## Router-first sequence

1. Read the request and underline the first stable noun.
2. Test that noun against [[router-existing-hub-entry-index-2026-05-07]].
3. If the noun maps to an existing entry, use [[process-existing-hub-entry-decision-2026-05-07]] and stop the new-hub idea.
4. If the noun maps only to a low-density exposed axis, route through [[section-low-density-hub-path-exposure-2026-05-07]] and choose a listed path, walkthrough, checklist, FAQ, or source note.
5. If no existing entry fits, write a one-line gap statement before creating any new hub.

## New-hub gate

- [ ] The gap is not just a different wording for institution/function, budget response, HR/personnel, or low-density route exposure.
- [ ] The candidate hub would collect at least three durable child notes or repeated routes.
- [ ] The candidate hub would reduce confusion more than a checklist, process, FAQ, or source note would.
- [ ] The candidate hub has a clear public-learning scope and does not require private records or internal deliberation.
- [ ] The handoff names the existing entries tested and why each was insufficient.

## Minimal handoff packet

```text
Input noun:
Existing entries tested:
Router-first result:
Gap statement, if any:
Decision: existing entry / section route / new hub candidate
```

## Stop / forbidden lines

- Stop if [[checklist-existing-hub-entry-decision-2026-05-07]] or [[process-existing-hub-entry-decision-2026-05-07]] already gives a sufficient existing entry.
- Stop if [[section-low-density-hub-path-exposure-2026-05-07]] already lists a usable route for the axis.
- Stop if any chosen wikilink is missing or points outside the root markdown surface.
- Stop if the request depends on private HR facts, personal data, non-public budget strategy, internal deliberation, or legal-advice conclusions.
- Forbidden in this lane: editing existing hubs, README.md, docs/index.html, landing files, graph/data files, generated catalogs, or the router artifact itself.
- Forbidden in this lane: commit, push, deletion, renaming, or broad refactor.
